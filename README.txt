MICROBAROMETER MISSION CONTROL DASHBOARD

1. Keep app.py and microbarometer_uncleaned_200.csv in the same folder.
2. Open this folder in VS Code.
3. Activate environment: .venv\Scripts\activate
4. Install packages: pip install -r requirements.txt
5. Run: python -m streamlit run app.py
6. Use the sidebar to turn moving charts on/off and change refresh interval.

Important: moving values are simulated for presentation and are not from actual hardware.
